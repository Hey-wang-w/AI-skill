### [1] 1-AI-ML-MODEL-KNN-01 🔥【薄弱点】
- 标题：k近邻分类器(k-NN)
- 级别：★★☆
- 来源：薄弱点到期
- 分类：阶段1：AI通识认知 → 人工智能 → 机器学习 → 经典模型 → k近邻
- 知识标签：机器学习、分类算法、k近邻、监督学习
- 掌握状态：🔴待复习（复习轮次：0）
- 核心内容：
最简单的分类器之一：**要分类一个新对象，找到训练数据中与它最相似（最近）的对象，输出其标签**。

**距离度量（“最近”的定义）**：
- **欧几里得距离**：二维/多维空间的直线距离（几何距离），适合数值特征
- **逐像素匹配**：图像分类中用像素灰度差异衡量相似度
- **共同购买计数**：推荐系统中用两个用户共同购买过多少商品衡量相似度
- ⚠️必须根据数据类型选择合适的距离度量，文本/图像/行为数据的距离定义各不相同

**k-NN的特点**：
- 优点：思想极简单、无需训练过程（“惰性学习”）
- 缺点：预测时需要计算与所有训练样本的距离，数据量大时很慢；模型=全部数据，可解释性差
- 问题：对图像的平移/缩放敏感（MNIST因为做了居中预处理缓解了这个问题）

**典型应用——协同过滤（Collaborative Filtering）**：
推荐系统核心算法：“过去行为相似的用户，未来行为也相似”。
- 你和其他用户过去听相似音乐 → 他们喜欢的新歌也推荐给你
- 注意练习题细节：**最近一次购买的商品不参与相似度计算**，留作预测目标
- 副作用：可能导致过滤气泡——只给你看和你观点相似的内容


### [2] 1-AI-ETHIC-BIAS-PRIV-01 🔥【薄弱点】
- 标题：AI时代的隐私威胁与去匿名化
- 级别：★★☆
- 来源：薄弱点到期
- 分类：阶段1：AI通识认知 → 人工智能 → AI伦理 → 偏见隐私 → 隐私威胁
- 知识标签：AI伦理、隐私、去匿名化
- 掌握状态：🔴待复习（复习轮次：0）
- 核心内容：
传统数据收集（商店会员卡）只记录购买；现代科技公司记录每一次点击、滚动、停留时长、浏览历史，精度前所未有。
AI带来的新威胁——去匿名化（De-anonymization）：
即使数据匿名化（去掉姓名身份证），通过组合多个看似无关的数据点仍能识别个人。
经典案例：
1. 邮编+出生年+性别：很多情况下可唯一识别一个人（像“1990年生北京朝阳区某邮编女性”可能只有几个人）
2. Netflix奖数据集：50万用户匿名评分，但研究人员通过和IMDb公开评分对比，成功识别出具体用户，泄露政治/性取向等隐私
3. 打字模式识别：赫尔辛基大学研究——按键间隔时间的模式像指纹，可跨网站识别用户身份
应对技术：差分隐私（Differential Privacy）——在统计结果中加入噪声，保证无法逆向工程出单个用户数据。


### [3] 1-AI-ML-DL-LLM-06 🔥【薄弱点】
- 标题：模型微调：全量微调 vs 参数高效微调(PEFT/LoRA)
- 级别：★★☆
- 来源：薄弱点到期
- 分类：阶段1：AI通识认知 → 人工智能 → 机器学习 → 深度学习 → 大语言模型
- 知识标签：微调、PEFT、LoRA、全量微调、模型定制
- 掌握状态：🔴待复习（复习轮次：0）
- 核心内容：
当提示工程无法满足垂直场景的性能、合规性、风格一致性要求时，需要通过模型调优做深度定制。

**何时需要调优（适用场景）**：
1. **性能要求极高**：通用提示无法达到业务要求的准确率
2. **合规性要求**：行业法规要求输出必须符合特定规范（如医疗、法律）
3. **风格一致性**：需要模型输出严格遵循特定文风、格式或术语体系
4. **领域专业性**：需要模型深度掌握垂直领域专业知识
例：情感分析等任务可使用专项调优模型；法律、医疗领域可基于专业数据调优适配行业需求。

**两类调优技术路径**：

**1. 全量微调（Full Fine-tuning）**
- 方法：带入自有数据集，调整预训练模型中的**所有权重参数**，对模型做完整重新训练
- 特点：定制化程度最高，但训练成本高、计算资源需求大、工作量大，需要自行托管调优后的专属模型
- 示例：基于医疗专业数据训练医疗领域基础模型，支持医疗问答、医学图像分析等专业任务

**2. 参数高效微调（PEFT, Parameter-Efficient Fine-Tuning）**
- 方法：一类轻量化调优方案统称，调优过程**不修改基础模型主体权重**，仅引入并训练极少量可训练参数
- 主流技术路线：LoRA（低秩适配）、Prefix Tuning、Adapter Tuning等（并非都以"附加层"形式实现）
- 优势：训练成本远低于全量微调；不同场景的调优参数可在推理时灵活切换，无需复制多份全量模型

### [6] 1-AI-INTRO-PHIL-TURING-01 
- 标题：图灵测试（Turing Test）
- 级别：★★★
- 来源：到期常规
- 分类：阶段1：AI通识认知 → 人工智能 → AI导论 → 哲学本质 → 图灵测试
- 知识标签：AI哲学、图灵测试
- 掌握状态：🟡学习中（复习轮次：1）
- 核心内容：
**图灵测试**（原名“模仿博弈”，Imitation Game）是图灵提出的判断机器是否具有智能的方法：
- 一名人类审讯者通过**纯文字聊天**与两名玩家（一个人类、一个计算机）互动
- 如果审讯者**无法区分**谁是计算机、谁是人类，则计算机通过测试
- 核心思想：**“智能就是智能所说”**——如果实体在对话行为上与智能实体无法区分，就可以认为它是智能的

**图灵测试的实际问题——像人类≠智能**：
一个著名的反例是**尤金·古斯特曼（Eugene Goostman）**，一个伪装成13岁乌克兰男孩的聊天程序：
- 它通过不断**转移话题**、犯拼写错误、开玩笑回避问题来“通过”测试
- 30名评委中骗过了10名（33%）
- 典型对话：问“骆驼有几条腿？”答“大概2到4条，也许三条？:-)))”
- 问题：这测出来的更像是“像不像人类”而非“是否智能”

**延伸**：图灵还对计算机科学有革命性贡献——提出**图灵机**（理论计算模型），证明任何可计算的事物都可自动化，奠定了可编程计算机的基础。图灵本人参与了二战期间破解德军密码的项目。

**易混/考点**：图灵测试测的是“行为是否像人类”，而非“是否真正理解”。这是后续中文房间论证攻击的要点。

- 级别：★★★
- 来源：到期常规
- 分类：阶段1：AI通识认知 → 人工智能 → AI导论 → 哲学本质 → 中文房间
- 知识标签：AI哲学、中文房间
- 掌握状态：🟡学习中（复习轮次：1）
- 核心内容：
中文房间是塞尔提出的**思想实验**，用来反驳“行为像智能=有智能”的观点：

**实验设定**：
- 一个**不懂中文**的人被锁在房间里
- 房间外有人从邮槽塞入中文纸条
- 房间内的人有一本**巨大的手册**，里面有详细的回复说明（类似程序规则）
- 人按照手册操作，也能用中文写出回复，塞出房间

**论证逻辑**：
- 房间外的人以为自己正在和一个懂中文的人交流
- 但房间内的人**完全不懂中文**，只是在机械执行规则
- 同理，即使机器通过了图灵测试（行为像智能），也**不能推断它真正有智能或有“心智”**

**与自动驾驶汽车的类比**：
- 自动驾驶汽车能智能地开车，但根据塞尔的观点，它并不真正“理解”环境
- 它只是机械执行程序，智能行为 ≠ 真正的智能思维

**实际影响**：约翰·麦卡锡指出，AI哲学“对AI研究实践的影响不会超过科学哲学对科学实践的影响”。因此AI研究更多关注解决实际问题的系统，而不纠结于它们是否“真正智能”。

**记忆口诀**：中文房间 = “行为像” ≠ “真的是”；塞尔攻击的是图灵测试的行为主义假设。

### [9] 1-AI-ML-PROB-ODDS-01 
- 标题：概率与赔率（自然频率）的基础换算
- 级别：★★★
- 来源：到期常规
- 分类：阶段1：AI通识认知 → 人工智能 → 机器学习 → 概率统计基础 → 概率赔率
- 知识标签：概率、统计、自然频率
- 掌握状态：🟡学习中（复习轮次：1）
- 核心内容：
**概率（Probability）**：事件发生次数 / 总次数，范围 0~1（或 0%~100%），如 3/4=0.75=75%

**赔率/自然频率（Odds）**：x:y 的形式，表示“发生x次对不发生y次”。如 3:1 意味着每3次发生对应1次不发生

**换算公式**：
- 赔率 x:y → 概率 = **x / (x+y)**
  - 例：3:1 → 3/(3+1) = 3/4 = 0.75
- 赔率 x:y 可约分：3:1 = 6:2 = 30:10（因为比例相同）

**为什么用自然频率而非百分比？**
- 研究发现人类在处理**自然频率**（整数比）时出错更少，比分数和百分比更直观
- 例：“四人中有三人是棕色眼睛”比“75%是棕色眼睛”更容易正确理解

**⚠️ 关键区分——赔率≠概率**：
- 赔率 1:5 = 1/5 = 0.2（赔率值），但对应的**概率**是 1/(1+5) = 1/6 ≈ 16.7%
- 赔率 1:5 ≠ 20%概率！1:5意味着6次中发生1次（≈16.7%），而非5次中1次
- 赔率 ＞ 1（如5:1）不可能混淆（没有概率能＞1）；赔率 ＜ 1（如1:5）是混淆高发区

**练习结论**（参考答案）：
- 扑克三条：1:46 → 概率 1/47 ≈ 2.1%
- 赫尔辛基降雨：206:159 → 概率 206/365 ≈ 56.4%
- 圣地亚哥降雨：23:342 → 概率 23/365 ≈ 6.3%

**记忆口诀**：赔率到概率，分母是两边相加——x:y → x/(x+y)。


### [10] 1-AI-ML-PROB-FALLACY-01 
- 标题：基础比率谬误（Base Rate Fallacy）
- 级别：★★★
- 来源：到期常规
- 分类：阶段1：AI通识认知 → 人工智能 → 机器学习 → 概率统计基础 → 推理谬误
- 知识标签：概率、贝叶斯、认知谬误
- 掌握状态：🟡学习中（复习轮次：1）
- 核心内容：
**定义**：当人们面对两个矛盾的证据时，倾向于**过度重视某个显著证据**（如阳性检测结果），而**忽视基础比率**（如疾病本身的稀有程度），导致推理错误。

**经典案例——乳腺癌筛查**（虚构数字）：
- 基础患病率：每100名女性中5人患病（**先验赔率 = 5:95**）
- 检测敏感度：患癌者80%被查出（真阳性率 = 80/100）
- 检测特异性：未患癌者10%被误报（假阳性率 = 10/100）
- 似然比 = 80/100 ÷ 10/100 = **8**

**应用贝叶斯规则**：
- 后验赔率 = 8 × 5 : 95 = **40:95**
- 后验概率 = 40/(40+95) = 40/135 ≈ **30%**

**为什么人的直觉会错？**
大多数人的直觉答案是“患癌概率应该很高（比如80%）”——因为被“检测阳性→80%准确”这个显著证据牵引，而忽略了“癌症本身很罕见（5%）”这个基础比率。

**贝叶斯规则是最好的解毒剂**：它强迫你同时考虑两个方向的证据，不会偏向任何一方。

**结论**：即使检测呈阳性，实际患病概率也只有约30%（远低于直觉估计）。这不是检测不准，而是因为基础患病率太低。

**记忆要点**：别被显著信号冲昏头脑——基础比率（先验）永远是贝叶斯推理的起点，不能跳过。


### [11] 1-AI-SEARCH-GAME-MINIMAX-01 
- 标题：博弈树与极小极大（Minimax）算法
- 级别：★★★
- 来源：到期常规
- 分类：阶段1：AI通识认知 → 人工智能 → 问题求解 → 博弈决策 → 极小极大
- 知识标签：博弈论、搜索算法、Minimax
- 掌握状态：🟡学习中（复习轮次：1）
- 核心内容：
游戏AI的经典方法——将所有可能走法展开成树状结构进行分析。

**博弈树（Game Tree）的结构**：
- **节点**：游戏的某个状态（棋盘局面）
- **根节点**：当前局面（通常是游戏中间某步，非从头开始）
- **层级交替**：每位玩家的回合构成一层——一层Min（轮到O），一层Max（轮到X），交替进行
- **叶节点**：游戏结束的状态（有人赢或平局）
- **分支因子**：每个节点的平均可选走法数（国际象棋≈35，围棋≈250）

**节点赋值——谁赢？**：
- Max赢的局面（X三连成线）= **+1**
- Min赢的局面（O三连成线）= **-1**
- 平局 = **0**
- 其他游戏可取任意数值（如扑克中用筹码金额）

**极小极大算法（Minimax）的核心推理**：
1. 从叶节点开始倒推：叶节点的值已知（胜负平）
2. **Max层**：轮到Max走，她会选**值最大的**子节点（因为她想赢）
3. **Min层**：轮到Min走，她会选**值最小的**子节点（因为她也想赢，但和Max是零和关系）
4. 一层一层从底向上传递，最终**根节点的值就是游戏的结果**
5. 如果双方都走最优步，根节点的值就能预判谁赢（或平局）

**经典示例——井字棋局面分析**：
教材中分析了一个中间局面：虽然Max可以封堵Min的连三，但Min只需在右下角落子就必胜（Minimax分析得出根节点值为-1，Min必胜）。

**前提条件**：Minimax适用于**确定性、两人、完美信息、零和博弈**（国际象棋✅、井字棋✅；扑克/西洋双陆棋因随机性❌；石头剪刀布因隐藏信息❌）

**记忆口诀**：Max选最大，Min选最小，从底往上倒推，根节点预判胜负。


### [12] 1-AI-SEARCH-GAME-HEUR-01 
- 标题：启发式评估函数与搜索的局限性
- 级别：★★★
- 来源：到期常规
- 分类：阶段1：AI通识认知 → 人工智能 → 问题求解 → 博弈决策 → 启发式评估
- 知识标签：博弈论、启发式、搜索算法
- 掌握状态：🟡学习中（复习轮次：1）
- 核心内容：
Minimax算法理论上完美，但实际面临**组合爆炸问题**，需要工程技巧。

**问题：游戏树太大，无法完整遍历**
｜ 提前看几步 ｜ 国际象棋需访问的节点数（分支≈35） ｜ 围棋需访问的节点数（分支≈250） ｜
｜-----------｜--------------------------------｜-------------------------------｜
｜ 2步 ｜ 35² ≈ 1,225 ｜ 250² ≈ 62,500 ｜
｜ 3步 ｜ 35³ ≈ 42,875 ｜ 250³ ≈ 1560万 ｜
｜ 4步 ｜ 35⁴ ≈ 150万 ｜ 250⁴ ≈ 39亿 ｜
｜ 10步 ｜ 35¹⁰ ≈ 2.7千万亿 ｜ — ｜

**解决方案：启发式评估函数（Heuristic Evaluation Function）**
- 在树的某个深度**提前停住**（不走到叶节点），用启发式函数给当前局面打分
- 函数输入=棋盘局面（含轮到谁走），输出=一个估算分数（这局面对Max有多好）
- **国际象棋启发式例子**：
  - 算棋子材料值：后≈9分，车≈5分，象/马≈3分，兵≈1分，王=无限大
  - 占据棋盘中心附近的战略位置=加分

**深度限制版Minimax**：只需在标准Minimax中设定一个深度上限，到达该深度时调用启发式函数而非继续展开。1997年深蓝击败卡斯帕罗夫就依赖了大量这种技巧。

**搜索方法的根本局限**：
1. **组合爆炸**：即使是中等复杂的现实问题，状态数也会失控增长，“暴力穷举”行不通
2. **非确定性**：现实世界中的转移往往不是确定性的（行动不保证结果），需要引入**概率和不确定性**（第三章内容）
3. 这意味着搜索方法适用于**简化/封闭领域**问题，扩展到真实世界需要结合概率推理

**记忆要点**：Minimax是完美的理论，但现实中用“走到一定深度+启发式打分”来近似，深蓝就是这样赢得国际象棋的。


### [13] 1-AI-ML-MODEL-NB-01 
- 标题：朴素贝叶斯分类器
- 级别：★★★
- 来源：到期常规
- 分类：阶段1：AI通识认知 → 人工智能 → 机器学习 → 经典模型 → 朴素贝叶斯
- 知识标签：机器学习、分类算法、朴素贝叶斯、监督学习
- 掌握状态：🟡学习中（复习轮次：1）
- 核心内容：
朴素贝叶斯是贝叶斯规则在**分类任务**中的直接应用——将文本等对象分到两个或多个类别中。

**工作原理（以垃圾邮件过滤为例）**：
- 类别变量 = 消息是垃圾邮件(spam)还是正常邮件(ham)
- 特征变量 = 消息中的每个单词
- 先验赔率：通常假设 spam:ham = 1:1（一半是垃圾邮件，实际可能更高）
- **核心操作**：依次用每个单词的似然比乘以当前赔率，逐词更新信念

**“朴素”在哪里？**
核心假设：**在给定类别的前提下，各单词之间是条件独立的**。这意味着：
- 词与词之间没有依赖关系
- 词的顺序不重要
- 这显然是过度简化——比如“not good”和“good”完全相反，但朴素假设把它们独立处理

**→ 这就是为什么叫“朴素”（naive）——明知假设不成立，但实际效果依然很好。**

**名言**：“所有模型都是错的，但有些是有用的。”（统计学家 George E.P. Box）

**概率估计**：从训练数据中计算每个词在各类别中的出现频率
- 如 “million” 在spam中出现156次/总词数95791 ≈ 1/614
- “million” 在ham中出现98次/总词数306438 ≈ 1/3127
- 似然比 = (1/614) / (1/3127) = 3127/614 ≈ **5.1**

**零频率问题**：如果某个词在一个类别中从未出现（如 “conferences” 在spam中0次），计数为0会导致计算崩溃。解决方案：使用一个很小的下限值代替0（如 1/100000）。

**注意——“ham”的正确翻译**：
教材中将“ham”译为“业余无线电”是错误的。在反垃圾邮件语境中，**ham = 正常邮件/非垃圾邮件**（与spam对立）。Ham本意是火腿，源自俚语用法。

**记忆要点**：朴素贝叶斯 = 贝叶斯规则 + 条件独立假设 → 逐词更新 → 分类。虽然“朴素”，但好用。

### [15] 1-AI-ML-MODEL-LINREG-01 
- 标题：线性回归
- 级别：★★★
- 来源：到期常规
- 分类：阶段1：AI通识认知 → 人工智能 → 机器学习 → 经典模型 → 线性回归
- 知识标签：机器学习、回归算法、线性回归、监督学习
- 掌握状态：🟡学习中（复习轮次：1）
- 核心内容：
线性回归是最经典、最易解释的监督学习方法。核心思想：**预测值 = 各特征的加权求和（线性组合）**。

**购物账单类比**：
账单 = 2.5kg土豆 × 2€/kg + 1.0kg胡萝卜 × 4€/kg + 2瓶牛奶 × 3€/瓶 = 15€
- 购买数量 = **输入特征**
- 单价 = **系数/权重（coefficient/weight）**
- 总账单 = **预测输出**

**“线性”的含义**：输入每增加一个固定量，输出的增量固定。例如每多买1kg胡萝卜，账单固定加4€；多买2kg加8€。

**截距项（Intercept）**：所有权重为0时的基础输出值。比如预期寿命例子中“不吸烟、不吃蔬菜女性的基础寿命80岁”就是截距；咖啡-代码例子中“不喝咖啡也能写约10行代码”就是截距。

**预期寿命计算示例**（公式：寿命 = 80 + 性别(-5/0) - 0.5×每天烟数 + 1×每天蔬菜把数）：
- 男性、8支烟、2把蔬菜 → 80 - 5 - 4 + 2 = **73岁** ✅
- 男性、0支烟、6把蔬菜 → 80 - 5 + 6 = **81岁**（⚠️你之前算成78，注意符号和加减！）

**核心优势：可解释性极强**——每个权重直接告诉你对应因素的影响方向和大小（如吸烟每天减半年，吃蔬菜每天加一年）。

**实际应用**：房价预测、广告点击率、票房预测、犯罪率预测、保险定价等。


### [16] 1-AI-ML-CORE-OVERFIT-01 
- 标题：过拟合与训练/测试集划分
- 级别：★★★
- 来源：到期常规
- 分类：阶段1：AI通识认知 → 人工智能 → 机器学习 → 核心问题 → 过拟合
- 知识标签：机器学习、过拟合、泛化
- 掌握状态：🟡学习中（复习轮次：1）
- 核心内容：
**过拟合** = 模型在训练数据上表现极好，但在新数据上表现很差——本质是“死记硬背训练数据”，而非“学到真正规律”。

**直观比喻**：预测歌曲走红时，你总结规则“关于爱情+朗朗上口副歌→前20名”，发现两首例外就加“除非提到瑞典或瑜伽”——规则完美匹配历史数据，但对未来新歌预测反而变差。

**为什么ML容易过拟合？** ML算法能尝试海量不同“规则”，总能找到一个完美匹配训练数据的规则。越灵活的方法（如深度神经网络）越需要大量数据来避免过拟合；越受限的方法（如线性回归）相对不容易过拟合但可能欠拟合。

**核心防护措施——训练集/测试集划分**：
- **训练集（Training Data）**：用来训练模型、学习权重（占大头，如70-80%）
- **测试集（Test Data）**：完全独立的数据，只在最后评估时用一次，模拟“未来新数据”
- **绝对禁忌**：不能用测试数据来调参/选模型，否则测试集就“污染”了，评估结果会虚高

**数据科学家核心技能**：找到“既不太受限也不太灵活”的模型复杂度，在偏差（欠拟合）和方差（过拟合）之间平衡。


### [17] 1-AI-ML-CORE-PERF-01 
- 标题：机器学习性能的四大影响因素
- 级别：★★★
- 来源：到期常规
- 分类：阶段1：AI通识认知 → 人工智能 → 机器学习 → 核心问题 → 性能因素
- 知识标签：机器学习、性能优化
- 掌握状态：🟡学习中（复习轮次：1）
- 核心内容：
ML系统的表现好坏由四个因素决定：

1. **任务本身难度**：有些任务本身就不可能完美解决。例如极度潦草的手写数字，人类也无法100%辨认
2. **算法/方法选择**：不同方法适合不同任务，没有“一个算法统治所有问题”。实际中需要尝试多种方法对比
3. **训练数据量**：数据太少不可能得到好的分类器。灵活的模型（神经网络）比简单模型需要更多数据
4. **数据质量**：
   - 训练数据必须包含与任务相关的信息
   - 如果只用猫狗图片训练分类器，它就不可能识别船和车
   - 有偏见的数据会导致有偏见的预测（偏见问题后续章节讨论）

**评估指标要贴合业务**：
- **分类任务**：用分类误差（错误预测的比例）衡量
- **回归任务**：用预测值与真实值的差距衡量
- **不对称错误代价**：漏检行人比误报“幽灵行人”严重得多；定价过低比定价过高损失不同
- **可接受的误差水平**取决于场景——99%准确率的音乐推荐足够好，但99%安全的自动驾驶不可接受

**核心观点**：好的但不完美的预测往往比没有预测好；ML的价值在于快速、持续、不知疲倦地产生预测，即使不完美。

**⚠️相关≠因果**：数据中发现的规律是相关性，不一定是因果关系（如教育年限与寿命相关，但教育不一定直接导致长寿，可能由营养、医疗等混淆因素共同驱动）。


### [18] 1-AI-ML-DL-NN-02 
- 标题：人工神经元：加权求和+激活函数
- 级别：★★★
- 来源：到期常规
- 分类：阶段1：AI通识认知 → 人工智能 → 机器学习 → 深度学习 → 神经网络基础
- 知识标签：深度学习、神经网络、基础
- 掌握状态：🟡学习中（复习轮次：1）
- 核心内容：
人工神经元做两件事，完全可以类比你已经掌握的线性/逻辑回归：

**第一步：算线性组合（加权求和）**
```
z = 截距 + 权重₁×输入₁ + 权重₂×输入₂ + ... + 权重ₙ×输入ₙ
```
- **权重**（weight）= 每个输入的“重要性乘数”，类似购物时的单价；权重越大，该输入对结果影响越大
- **截距**（intercept/bias）= 不乘任何输入的基础项，类似购物的信用卡手续费
- **输入**= 特征数值，类似每种商品买几件

**第二步：通过激活函数输出**
算完z之后，不是直接输出z，而是把z喂给一个**激活函数**（activation function），得到最终输出。

**和回归的关系**：
- 如果激活函数是恒等函数 → 和**线性回归完全一样**
- 如果激活函数是S形 → 和**逻辑回归完全一样**
- 神经网络就是大量这样的“小神经元”串并联而成


### [19] 1-AI-ML-DL-NN-03 
- 标题：三种经典激活函数（恒等/阶跃/Sigmoid）
- 级别：★★★
- 来源：到期常规
- 分类：阶段1：AI通识认知 → 人工智能 → 机器学习 → 深度学习 → 神经网络基础
- 知识标签：深度学习、神经网络、激活函数
- 掌握状态：🟡学习中（复习轮次：1）
- 核心内容：
激活函数决定了神经元如何把加权和z变成最终输出。三种最经典的：

｜ 激活函数 ｜ 规则 ｜ 输出范围 ｜ 特点 ｜
｜---------｜------｜---------｜------｜
｜ **恒等函数（Identity）** ｜ 输出 = z，什么都不做 ｜ (-∞, +∞) ｜ 就是线性回归，基本不用（纯堆叠没用） ｜
｜ **阶跃函数（Step）** ｜ z ＞ 0 → 输出1；z ≤ 0 → 输出0 ｜ {0, 1}二值 ｜ 模仿生物神经元“点火/不点火”，是**感知器**用的函数 ｜
｜ **S形函数（Sigmoid）** ｜ 1/(1+e⁻ᶻ) ｜ (0, 1)连续 ｜ 阶跃函数的“软版本”，是逻辑回归用的函数 ｜

**形象比喻**：
- 恒等函数 = 功放直接播放原音
- 阶跃函数 = **电灯开关**：电压够→灯亮（1），不够→灯灭（0）
- S形函数 = **调光旋钮**：可以平滑调节亮度，从全黑到最亮渐变

**练习22注意点（你答错过）⚠️**：
- 输入5时输出最高的是**恒等函数**（输出5），sigmoid接近1，step=1
- 输入**-5**时输出最低的是**恒等函数**（输出-5！），sigmoid接近0，step=0
- 输入-2.5时输出最高的是**阶跃函数**（输出0），sigmoid≈0.08，identity=-2.5
- （关键：恒等函数输出可以是负数！sigmoid和step最低就是0）


### [20] 1-AI-ML-DL-NN-04 
- 标题：权重大小的含义与影响
- 级别：★★★
- 来源：到期常规
- 分类：阶段1：AI通识认知 → 人工智能 → 机器学习 → 深度学习 → 神经网络基础
- 知识标签：深度学习、神经网络、权重
- 掌握状态：🟡学习中（复习轮次：1）
- 核心内容：
权重wᵢ意味着“**输入i每变化1单位，输出z变化wᵢ单位**”。所以：
- **权重绝对值越大**→ 这个输入“说话越管用”，输入只需变化一点点，输出就能有大变化
- **权重=0**→ 这个输入被忽略，不管你怎么变，对输出都没影响（就像练习题中第五个输入权重0.0，加1啥都不发生）
- **权重是负数**→ 输入越大，输出越小（反向影响）

**练习21你答错的题⚠️**：
问“哪种输入改变最少就能让输出增加一定量”→ 答案是**权重最大的那个输入**（第四个，权重101.4）。
直觉类比：**推一扇很重的门，你想让门开得更多，推最省力的那个位置（也就是权重最大的输入），只需推一点点就有大效果**。

**购物账单例子**：
- 土豆2€/kg，电视1000€/台
- 想让总账单多1000€：土豆要买500kg才够（权重小要大变动），电视只要多买1台（权重大，小变动就行）
- 所以**权重越大，输入改变越少就能改变输出**。
